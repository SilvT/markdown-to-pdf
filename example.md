# Sample Document

This is an example Markdown document to demonstrate the PDF conversion tool.

## Introduction

This tool converts Markdown files into beautifully formatted PDF documents. You can customize the styling using the `config.yaml` file.

## Features

The converter supports the following Markdown features:

- **Bold text**
- *Italic text*
- Ordered and unordered lists
- Headings (H1 through H6)
- Links and emphasis
- Code blocks and inline code
- Blockquotes

### Lists

Here's an unordered list:

- First item
- Second item
- Third item with a [link](https://example.com)

And an ordered list:

1. First step
2. Second step
3. Third step

### Code Examples

You can include inline code like `print("Hello, World!")` or code blocks:

```python
def greet(name):
    return f"Hello, {name}!"

print(greet("World"))
```

### Blockquotes

> This is a blockquote. It can be used for citations or to highlight important information.
>
> Multiple paragraphs are supported.

## Conclusion

Edit the `config.yaml` file to change fonts, colors, margins, and more. Enjoy creating your PDFs!
